\section{Methodology}
\label{sec:methods}

\subsection{Physical system and forecasting problem}
\label{sec:methods:problem}

We consider the response of a dynamical system to a prescribed control trajectory. Its evolution is represented by
\begin{equation}
 \dot{\mathbf{x}}(t)=\mathbf{f}\bigl(\mathbf{x}(t),\mathbf{u}(t)\bigr)
 \qquad
 \mathbf{y}(t)=\mathbf{g}\bigl(\mathbf{x}(t),\mathbf{u}(t)\bigr).
 \label{eq:mace:system}
\end{equation}
Here $\mathbf{x}(t)$ is the physical state and $\mathbf{u}(t)$ is the prescribed control. The vector $\mathbf{y}(t)\in\mathbb{R}^{J}$ contains the output variables of interest. These may include algebraic quantities as well as directly integrated states. A control trajectory defines the input over time. Its corresponding multivariate response trajectory is obtained from the reference simulator. Together they form one trajectory sample for model development and evaluation.

The forecasting task is to predict $\mathbf{y}$ over a specified horizon using an initial history and the subsequent control trajectory. For trajectory $i$ we denote the reference output at forecast step $h$ by $\mathbf{y}_{i,h}$. The forecast contains $H$ steps with $h=0,\ldots,H-1$. Each output variable is indexed by $j=1,\ldots,J$. The present study uses $J=15$ outputs and $H=501$ forecast points over 200~s with a sampling interval of 0.4~s. The twelve reactor control drums follow the same angular trajectory $\theta(t)$. All predictions are produced recursively from the initial history. Simulator responses are used for training and subsequent evaluation but are not supplied during the forecast.

We distinguish between the distribution used to calibrate prediction intervals and the distribution used to evaluate them. Calibration is performed using independent complete trajectories. This choice preserves correlations among time steps and output variables within each trajectory. The associated coverage objectives are defined in Section~\ref{sec:methods:mace}.

\subsection{Stochastic control-trajectory sampling}
\label{sec:methods:sampling}

Control trajectories were generated by sampling correlated angular velocities and integrating them over time. This approach provides temporally structured excitation without selecting individual actuator angles independently at each time step. The velocity covariance determines the characteristic time scale of control motion while integration determines the corresponding angular trajectory.

We use the Mat\'ern-$5/2$ covariance for the sampled angular velocity $v(t)=\dot{\theta}(t)$. Its correlation function is
\begin{equation}
 \rho(\Delta t)=
 \left(1+\frac{\sqrt{5}\Delta t}{\ell}
       +\frac{5\Delta t^2}{3\ell^2}\right)
 \exp\left(-\frac{\sqrt{5}\Delta t}{\ell}\right).
 \label{eq:mace:matern}
\end{equation}
The parameter $\ell$ is the correlation length. The covariance matrix for the interval velocities is
\begin{equation}
 C_{rs}=\sigma_v^2\rho\bigl(|t_r-t_s|\bigr)
       +(\sigma_n^2+\varepsilon_{\mathrm{cov}})\delta_{rs}.
 \label{eq:mace:velocitycov}
\end{equation}
Here $\sigma_v^2$ is the velocity sill and $\sigma_n^2$ is the nugget variance. The small diagonal term $\varepsilon_{\mathrm{cov}}$ provides numerical stability. The corresponding stationary velocity semivariogram is $\gamma(\Delta t)=\sigma_v^2[1-\rho(\Delta t)]$ when the nugget and numerical jitter are omitted. The integration of velocity produces a nonstationary angle process.

The control interval is $\Delta t_c=0.1$~s and the time domain is 0--200~s. A sampled velocity vector contains $L=2000$ interval values. Angular position is obtained from
\begin{equation}
 \theta_k=\theta_0+\Delta t_c\sum_{r=0}^{k-1}v_r
 \qquad  k=1,\ldots,L
 \label{eq:mace:integratedcontrol}
\end{equation}
with $\theta_0=45^\circ$. The first sampled interval velocity is conditioned to zero. For an unconditioned Gaussian velocity draw the implementation applies
\begin{equation}
 v_r\longleftarrow v_r-
 \frac{C_{r0}}{C_{00}+\varepsilon_c}v_0
 \label{eq:mace:conditioning}
\end{equation}
and subsequently sets $v_0=0$ exactly. The regularization term $\varepsilon_c$ avoids numerical instability. The resulting angle is stored on the control grid and is interpolated by the Modelica simulation.

The velocity sill is chosen to provide a specified standard deviation of angular displacement at the final time for the unconditioned process. For zero nugget and negligible numerical jitter this is expressed as
\begin{equation}
 \sigma_v^2=
 \frac{(\sigma_\theta^{\star}/\Delta t_c)^2}
 {L+2\displaystyle\sum_{r=1}^{L-1}(L-r)\rho(r\Delta t_c)}.
 \label{eq:mace:sill}
\end{equation}
The design value is $\sigma_\theta^{\star}=2.5^\circ$. The retained configuration uses $\ell=10$~s and zero nugget with a random seed of 123. The covariance jitter fraction and initial-conditioning regularization are both $10^{-10}$. The endpoint dispersion in Eq.~\eqref{eq:mace:sill} is defined before conditioning and rejection. It is therefore not the final standard deviation of the accepted angular trajectories.

Generated profiles are rejected if their angular positions leave the interval $0^\circ$--$180^\circ$. The original dataset was also specified to contain trajectories with $|v|<1^\circ/\mathrm{s}$. This angular-velocity criterion applies to the retained profiles and should not be interpreted as an explicit speed limit in the current covariance generator. The original velocity records are needed to verify the maximum realized rate over the complete dataset. Figure~\ref{fig:mace:sampling} illustrates the correlation function and the relationship between sampled velocity and angular position.

Each accepted control trajectory is supplied to the reference simulator. The corresponding multivariate responses are recorded at 0.4-s intervals. The original dataset contains 5{,}000 training trajectories and 1{,}000 validation trajectories. Separate sets of 1{,}000 calibration trajectories and 2{,}000 evaluation trajectories are used for uncertainty analysis. The partitions contain complete trajectories rather than individual time steps. Independence of the original partitions remains subject to confirmation from the archived sampling and genealogy records.

\subsection{Autoregressive LSTM ensemble}
\label{sec:methods:forecasting}

A ten-member ensemble of long short-term memory networks is used to predict the response of the simulator. Each model receives a short history of the output variables together with a shifted sequence of prescribed controls. The network predicts the output vector at the next time step. Its architecture consists of one LSTM layer with 64 hidden units followed by a fully connected layer with 64 units and a rectified linear activation. A final linear layer predicts the 15 output variables.

Training data are normalized using the minimum and range of each variable computed from the training partition. Input and output scaling are fitted separately. We represent these transformations by
\begin{equation}
 \mathcal{S}_{\mathrm{in}}(z)=
 \frac{z-z_{\min}^{\mathrm{in}}}{z_{\max}^{\mathrm{in}}-z_{\min}^{\mathrm{in}}}
 \qquad
 \mathcal{S}_{\mathrm{out}}(y)=
 \frac{y-y_{\min}^{\mathrm{out}}}{y_{\max}^{\mathrm{out}}-y_{\min}^{\mathrm{out}}}.
 \label{eq:mace:scaling}
\end{equation}
The operations are applied independently to each feature. Constant features use a unit range. The same fitted transformations are used during validation and all subsequent forecasts. We denote normalized output values by $\widetilde{\mathbf y}=\mathcal{S}_{\mathrm{out}}(\mathbf y)$.

The lookback parameter is $K=12$. Each training input contains $K+1=13$ rows and 16 features per row. To predict $\mathbf y_{k+1}$ the input rows contain
\begin{equation}
 \mathbf{z}_{k,r}=
 \left[
 \mathcal S_{\mathrm{in}}\bigl(\mathbf y_{k-K+r}\bigr)
 \quad
 \mathcal S_{\mathrm{in}}\bigl(\mathbf u_{k-K+1+r}\bigr)
 \right]
 \qquad r=0,\ldots,K.
 \label{eq:mace:window}
\end{equation}
The output-history window extends from $k-12$ through $k$. The prescribed control window extends from $k-11$ through $k+1$. Hence the control at the prediction time is available while the associated reference output is not. The initial sequence is prepared from the common steady operating condition.

Ensemble diversity is introduced through independent training subsets. Each member receives 70\% of the available training trajectories sampled without replacement. The subsets may overlap across members. This procedure differs from bootstrap resampling with replacement. Models are optimized using mean squared error and Adam with an initial learning rate of $3\times10^{-4}$. The batch size is 64 and the maximum training duration is 100 epochs. The learning rate is halved every 30 epochs. For each member the checkpoint with the lowest validation loss is retained. Table~\ref{tab:mace:training} summarizes the model configuration.

During autoregressive forecasting each ensemble member advances independently. After the initial history has been supplied the model's previous prediction is used to construct its next input. Because the input and output scalers differ the predicted outputs must be converted to input-scaled coordinates before they are fed back. For member $m$ this mapping is
\begin{equation}
 \widehat{\mathbf y}_{m,h}^{\,\mathrm{in}}
 =\mathcal{S}_{\mathrm{in}}\!
 \left(\mathcal{S}_{\mathrm{out}}^{-1}
 \left(\widehat{\widetilde{\mathbf y}}_{m,h}\right)\right).
 \label{eq:mace:feedback}
\end{equation}
The oldest history row is then replaced with the mapped prediction and the prescribed control window is advanced. Each member uses its own predictions rather than the ensemble mean. The reference simulator output is not used after initialization. This recurrence is applied consistently in the operation-informed forecast evaluation. Original stochastic archives must be reconciled using the same mapping before comparative numerical results are finalized.

The mean and standard deviation of the ensemble are calculated at each horizon for each output. With $M=10$ members the estimates in normalized output coordinates are
\begin{equation}
 \mu_{i,h,j}=\frac{1}{M}\sum_{m=1}^{M}\widehat y_{i,h,j}^{(m)}
 \qquad
 \sigma_{i,h,j}=
 \sqrt{\frac{1}{M}\sum_{m=1}^{M}
 \left(\widehat y_{i,h,j}^{(m)}-\mu_{i,h,j}\right)^2}.
 \label{eq:mace:ensemble}
\end{equation}
Here $\widehat y_{i,h,j}^{(m)}$ denotes member $m$'s normalized output prediction. We use the population standard deviation with denominator $M$. The spread $\sigma$ measures disagreement between ensemble predictions and is not assumed to represent a calibrated predictive probability distribution. Figure~\ref{fig:mace:lstm} illustrates the model architecture and individual autoregressive prediction paths.

\subsection{Multivariate Adaptive Conformal Ensemble}
\label{sec:methods:mace}

MACE combines ensemble disagreement with conformal prediction to construct adaptive uncertainty intervals. The central forecast is the ensemble mean $\mu_{i,h,j}$ and the interval scale is obtained from the member spread $\sigma_{i,h,j}$. A positive constant $\epsilon$ is added to the spread to avoid division by zero. The normalized nonconformity score for calibration trajectory $i$ is
\begin{equation}
 s_{i,h,j}=
 \frac{\left|\widetilde y_{i,h,j}-\mu_{i,h,j}\right|}
 {\sigma_{i,h,j}+\epsilon}.
 \label{eq:mace:score}
\end{equation}
The additive floor is set to $\epsilon=10^{-3}$ in normalized output coordinates. It is common to all output variables and forecast horizons. When the spread is small the floor limits the sensitivity of the interval scale to minor differences among members. The conformal multiplier also changes with the scale and a larger floor does not necessarily produce a wider calibrated interval.

For a calibration set containing $N_{\mathrm{cal}}$ independent trajectories the conformal quantile is obtained from the ordered nonconformity scores. The order statistic is
\begin{equation}
 k=\left\lceil(N_{\mathrm{cal}}+1)(1-\alpha)\right\rceil
 \qquad
 q=S_{(k)}.
 \label{eq:mace:quantile}
\end{equation}
Here $\alpha$ is the target miscoverage probability and $S_{(k)}$ is the $k$th smallest calibration score for the selected event. We use $N_{\mathrm{cal}}=1000$ and $\alpha=0.05$ which gives $k=951$. Quantiles are calculated without interpolation. The resulting bounds for a new forecast are
\begin{equation}
 I_{h,j}=
 \left[
 \mu_{h,j}-q(\sigma_{h,j}+\epsilon)
 \;\;,\;\;
 \mu_{h,j}+q(\sigma_{h,j}+\epsilon)
 \right].
 \label{eq:mace:bounds}
\end{equation}
The score reduction determines which conformal quantile appears in Eq.~\eqref{eq:mace:bounds}.

Three constructions are considered. \emph{MACE-Horizon} retains the score for each horizon and output variable. A separate conformal quantile $q_{h,j}$ is computed over calibration trajectories for every pair $(h,j)$. This provides a marginal coverage objective at each specified forecast coordinate. \emph{MACE-Trajectory} instead uses the largest normalized error over time for each output:
\begin{equation}
 S_{i,j}^{\mathrm{traj}}=\max_h s_{i,h,j}.
 \label{eq:mace:trajectoryscore}
\end{equation}
The corresponding quantile $q_j$ is calibrated across complete trajectories. This targets coverage over the entire evaluated forecast of one output variable. For joint trajectory calibration we take the maximum over time and output variables:
\begin{equation}
 S_i^{\mathrm{joint}}=\max_{h,j}s_{i,h,j}.
 \label{eq:mace:jointscore}
\end{equation}
A single quantile $q_{\mathrm{joint}}$ is then applied to all interval coordinates. This procedure targets coverage of every output variable over the complete forecast grid.

The coverage objectives differ in an important way. Marginal coverage for each output at one horizon is not equivalent to simultaneous coverage of all outputs at that horizon. We refer to the latter as \emph{Horizon complete multivariate coverage}. Similarly coverage of each output trajectory independently does not imply that all output trajectories are covered together. The joint construction targets \emph{Trajectory complete multivariate coverage}. These distinctions are illustrated in Figure~\ref{fig:mace:events}. The reported objectives refer to the discrete 501-point forecast grid.

Split conformal inference provides marginal coverage when the calibration and evaluation trajectory samples are exchangeable. Correlations between the time steps and output variables within a trajectory are retained in the score construction. The resulting guarantee applies to the selected coverage event over the evaluation population. It does not establish the same coverage separately for every operating condition or for every phase of an individual transient. A change in the evaluation distribution can invalidate the original guarantee unless the calibration procedure is adapted.

We compare MACE against absolute-error conformal prediction to examine the benefit of adaptive scaling. The baseline uses $s_{i,h,j}=|\widetilde y_{i,h,j}-\mu_{i,h,j}|$ and constructs intervals using the resulting quantiles without a spread multiplier. Both methods use the same calibration trajectories and order statistics. They also use the same horizon-based and trajectory-based coverage objectives. An uncalibrated envelope based only on ensemble spread is treated as a diagnostic rather than as a conformal prediction interval.

\subsection{Microreactor model and simulated transients}
\label{sec:methods:plant}

A reduced heat-pipe microreactor model was developed in Modelica and simulated using Dymola. The model couples point kinetics with lumped heat transfer through the reactor and balance of plant. It represents the response of a 6~MW thermal microreactor to the synchronized motion of twelve control drums. The model does not resolve spatial neutronics or individual heat-pipe flow fields. Its purpose is to provide a consistent transient simulation dataset for developing and evaluating the proposed forecasting method.

The neutronic response is represented using point kinetics with six delayed neutron groups. Reactor power is defined as $P=P_r n$ with $P_r=6$~MW and normalized neutron population $n$. The governing equations are
\begin{equation}
 \begin{aligned}
 \frac{dn}{dt}&=\frac{\rho-\beta}{\Lambda}n+
                 \sum_{r=1}^{6}\lambda_r c_r\\
 \frac{dc_r}{dt}&=\frac{\beta_r}{\Lambda}n-\lambda_r c_r.
 \end{aligned}
 \label{eq:mace:kinetics}
\end{equation}
Here $\beta_r$ is the delayed neutron fraction for group $r$ and $\lambda_r$ is its decay constant. The total delayed neutron fraction is $\beta$ and $\Lambda$ is the prompt neutron generation time. The reactivity combines drum worth with thermal feedback:
\begin{equation}
 \rho=\rho_d(\theta)+
       \alpha_f(T_f-T_{f,0})+
       \alpha_m(T_m-T_{m,0}).
 \label{eq:mace:reactivity}
\end{equation}
The drum worth follows the cosine relationship implemented in the simulator and is referenced to $\theta_0=45^\circ$. The coefficients $\alpha_f$ and $\alpha_m$ describe the fuel and moderator temperature feedback.

The thermal network contains five dynamic temperature nodes. These represent fuel $T_f$ and moderator or structure $T_m$ along with an effective heat-pipe node $T_{hp}$. The remaining nodes represent the nitrogen loop $T_{N2}$ and the steam-generator metal $T_{sg}$. Heat transfer between adjacent nodes is expressed using effective thermal conductances. The resulting equations account for the thermal response of the modeled components while avoiding spatial discretization of the individual flow paths. Figure~\ref{fig:mace:plant} illustrates the principal heat-transfer connections.

The steam-generator metal is treated as a dynamic thermal capacitance. Its energy balance is
\begin{equation}
 C_{sg}\frac{dT_{sg}}{dt}=Q_{N2,sg}-Q_{sg,fw}.
 \label{eq:mace:steammetal}
\end{equation}
The corresponding heat-transfer rates are
\begin{equation}
 \begin{aligned}
 Q_{N2,sg}&=G_{N2,sg}(T_{N2}-T_{sg})\\
 Q_{sg,fw}&=\max\!\left[G_{sg,fw}(T_{sg}-T_{\mathrm{sat}}),0\right].
 \end{aligned}
 \label{eq:mace:steamflows}
\end{equation}
The secondary heat addition is expressed as an increase in specific enthalpy $\Delta h=Q_{sg,fw}/\dot m_{fw}$. The simplified secondary closure gives
\begin{equation}
 x_{\mathrm{out}}=
 \min\left(1,\max\left(0,\frac{\Delta h}{h_{fg}}\right)\right)
 \label{eq:mace:quality}
\end{equation}
and
\begin{equation}
 T_{\mathrm{out}}=
 T_{\mathrm{sat}}+\frac{\max(\Delta h-h_{fg},0)}{c_{p,\mathrm{sh}}}.
 \label{eq:mace:steamclosure}
\end{equation}
Here $h_{fg}$ is the specified latent heat and $c_{p,\mathrm{sh}}$ is the effective heat capacity of superheated steam. The outlet quality and temperature are calculated outputs rather than boundary conditions. The feedwater mass flow rate is 2.95~kg/s and the outlet pressure is 1.5~MPa. The executed simulation wrapper specifies a steam-generator metal capacitance of $2.55\times10^5$~J/K. The simulation duration is 200~s with a numerical tolerance of $10^{-8}$.

The neural surrogate predicts 15 output variables. These comprise five thermal-node temperatures and six delayed precursor quantities together with neutron population and reactivity. The final two outputs are steam outlet temperature and quality. Table~\ref{tab:mace:outputs} lists the variables in their stored order. The model contains twelve differential states with the remaining three outputs determined algebraically. The precursor variables retain the normalization used in the Modelica model. The displayed transient dataset uses physical power $P=6n$~MW in place of normalized neutron population $n$ for visualization.

\subsection{Calibration distributions and operation-informed transients}
\label{sec:methods:transfer}

We evaluate MACE under the original stochastic control distribution and a second distribution based on prescribed operating maneuvers. The first provides a reference for assessing the surrogate under the conditions used to develop the training dataset. The second tests the application of the same forecasting models to control trajectories with different temporal characteristics. The objective is to distinguish changes in prediction accuracy from changes in uncertainty calibration.

The operation-informed distribution contains four equally weighted maneuver types. The first consists of a single upward motion followed by a hold. The second contains three successive upward motions separated by holding periods. The third consists of an upward motion followed by a return to the initial angle. The fourth includes motion above and below the initial angle before returning to the starting condition. Each trajectory begins at $45^\circ$ and is defined through piecewise-linear angular motion. The control parameters are selected from the ranges in Table~\ref{tab:mace:families}.

The maneuver parameters are sampled independently within each prescribed type. Times are rounded to the 0.4-s grid and the realized angular velocity is calculated from the resulting motion. Sampled schedules are rejected if they contain overlapping moves or violate the permitted angular limits. All trajectories remain within the study envelope of $44.25^\circ$--$48.75^\circ$. The resulting control signal is continuous and piecewise linear. Instantaneous changes of velocity occur at maneuver boundaries because actuator acceleration is not modeled explicitly. These maneuver types represent selected operating conditions rather than measured frequencies of reactor control actions.

The operation-informed calibration set contains 1{,}000 trajectories and the evaluation set contains 2{,}000 trajectories. They are generated independently from the same equally weighted mixture using the configured random seed 20261010. Model predictions for the evaluation trajectories are calculated once. We then construct prediction intervals using two calibration sources. The first uses the original stochastic calibration population. The second uses the independent operation-informed calibration population. The same ensemble predictions and scaler are used in both cases. Recalibration changes the conformal quantiles and interval bounds without changing the forecast mean or ensemble spread.

Calibration using the original stochastic trajectories provides a test of transfer to the new evaluation distribution. It does not have the standard split-conformal guarantee because the two populations are not exchangeable. Calibration and evaluation on independently generated operation-informed trajectories provide the usual pooled marginal coverage interpretation under the common mixture. This guarantee does not imply equal coverage for each individual maneuver type. Absolute-error conformal intervals are constructed using both calibration sources for comparison.

Performance is also examined during different portions of each control trajectory. Motion includes each interval of prescribed drum movement. Early settling consists of the following 20~s provided that another movement has not started. Initial hold precedes the first maneuver and late hold covers the remaining stationary periods. The same calibration thresholds are used in every phase. Table~\ref{tab:mace:arms} summarizes the calibration and evaluation populations.

\subsection{Evaluation metrics}
\label{sec:methods:metrics}

Forecast accuracy is quantified using the mean absolute error (MAE) and root mean square error (RMSE). Both metrics are calculated for each predicted output against the corresponding simulator response. To compare outputs with different physical units we also normalize their errors by the training range of each output. Aggregate MAE is obtained by averaging these normalized errors over the output variables. Aggregate RMSE is calculated from the mean normalized squared error before taking the square root. This prevents differences in physical magnitude from determining the relative contribution of each output.

The coverage of a prediction interval is calculated using an inclusive indicator:
\begin{equation}
 A_{i,h,j}=
 \mathbb{1}\!\left\{L_{i,h,j}\leq
 \widetilde y_{i,h,j}\leq U_{i,h,j}\right\}.
 \label{eq:mace:indicator}
\end{equation}
Coverage is reported for individual horizons and outputs as well as complete trajectories. The empirical per-output trajectory coverage is
\begin{equation}
 \widehat C_j^{\mathrm{traj}}=
 \frac{1}{N}\sum_{i=1}^{N}\prod_{h=0}^{H-1} A_{i,h,j}.
 \label{eq:mace:targetcoverage}
\end{equation}
The complete multivariate trajectory coverage is
\begin{equation}
 \widehat C^{\mathrm{joint}}=
 \frac{1}{N}\sum_{i=1}^{N}
 \prod_{h=0}^{H-1}\prod_{j=1}^{J}A_{i,h,j}.
 \label{eq:mace:jointcoverage}
\end{equation}
Horizon complete multivariate coverage is obtained by taking the product over all outputs at a specified horizon. These quantities describe different events and are reported separately. Coverage during motion and settling is evaluated over the corresponding subsets of each trajectory. Phase-specific results are diagnostic and are not assigned separate conformal guarantees.

We assess interval efficiency using the full interval width $W=U-L$. Output-specific widths are reported in physical units using the stored scaling factors. Aggregate widths are calculated in normalized coordinates with equal weight given to each output. Relative width reduction is measured against the corresponding absolute-error conformal baseline:
\begin{equation}
 R_W=1-\frac{\overline W_{\mathrm{MACE}}}{\overline W_{\mathrm{CP}}}.
 \label{eq:mace:widthratio}
\end{equation}
A positive value indicates a reduction in mean width relative to the baseline. Since narrow intervals may fail to contain the reference response we also evaluate the interval score~\cite{gneiting2007scoring}:
\begin{equation}
 \mathrm{IS}_{\alpha}(L,U,y)=
 (U-L)+\frac{2}{\alpha}(L-y)_+
       +\frac{2}{\alpha}(y-U)_+.
 \label{eq:mace:intervalscore}
\end{equation}
The positive-part operator is defined as $(z)_+=\max(z,0)$. Lower interval scores are preferable because the metric penalizes width and observations outside the interval. For trajectory-based methods this remains a pointwise interval diagnostic. The simultaneous coverage event is assessed separately.

Accuracy and interval width are averaged over the time points included in each comparison. Whole-trajectory coverage counts each supported trajectory once. This distinction is retained when assessing periods of differing duration. In addition to the aggregate results we report performance separately for the four maneuver types and for the motion and holding phases.

Confidence intervals for evaluation metrics are estimated using 10{,}000 paired bootstrap replicates. Each replicate resamples complete evaluation trajectories with replacement. A common set of resampled trajectory indices is used for both calibration approaches and for the MACE and absolute-error conformal methods. This preserves temporal dependence within each trajectory and permits paired comparisons on the same evaluation cases. The resulting 95\% percentile intervals quantify variation due to the finite evaluation sample. They are conditional on the trained models and calibration datasets and do not account for retraining uncertainty or repeated recalibration.

Nonconformity scores and interval endpoints are calculated in normalized output coordinates using float32 arrays. Coverage is evaluated using inclusive endpoint comparisons in the same coordinates. Float64 arithmetic is then used for interval widths and interval scores. Forecast accuracy is evaluated against the simulator responses in their native physical units. The retained model checkpoints and scaler are used throughout the distribution comparison.
