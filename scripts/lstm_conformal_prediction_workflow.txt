MACE conformal prediction workflow from saved ensemble forecasts
===============================================================

This document describes the current role of scripts/run_lstm_conformal_prediction.py.
The script no longer builds datasets, trains LSTM models, trains bagged ensembles,
loads ensemble checkpoints, or runs ensemble autoregressive inference.  Those steps
belong upstream, for example in scripts/train_lstm_ensemble.py.

The conformal script now consumes saved ensemble audit forecast files and applies
the five UQ methods, including Multivariate Adaptive Conformal Ensemble (MACE) variants to exactly the same cached calibration and test predictions.

Required inputs
---------------

The JSON config must provide:

  - scaled_h5_path
      A scaled train/val/cal/test HDF5 file containing the /scaling metadata used
      to descale final truth, ensemble means, and interval bounds.

  - calibration_ensemble_forecasts_audit_h5_path
      The saved calibration ensemble forecast audit HDF5.  This file must contain
      one group per calibration profile with scaled truth, scaled member
      predictions, scaled ensemble mean, and scaled ensemble standard deviation.

  - test_ensemble_forecasts_audit_h5_path
      The saved test ensemble forecast audit HDF5 with the same schema as the
      calibration audit file.

  - train_manifest_path, val_manifest_path, cal_manifest_path, test_manifest_path
      Four required manifest JSON files.  They must contain train_profiles,
      val_profiles, cal_profiles, and test_profiles, respectively.  The script
      validates that the four manifest sets are mutually disjoint and that the
      saved forecast HDF5 profile groups match the cal and test manifests.

  - uq_output_dir
      Directory where the conformal comparison artifacts are written.

The config intentionally does not accept dataset-building, split-fraction,
training, checkpoint-loading, or ensemble-source fields.  In particular, do not
include sim_root, batches, unscaled_out_dir, scaled_out_dir, out_dir,
train_frac, val_frac, cal_frac, test_frac, ensemble_source, or
ensemble_checkpoint_paths.

Example command
---------------

    PYTHONPATH=src python scripts/run_lstm_conformal_prediction.py \
      --config scripts/lstm_conformal_prediction_config.json

Saved forecast schema expected by the conformal script
------------------------------------------------------

Each audit forecast file should have root attributes:

  - target_names
  - member_count or ensemble_member_count
  - ensemble_std_ddof or ensemble_ddof

Each profile group should contain:

  - t
  - control or u
  - y_true_scaled
  - member_predictions_scaled          shape: (n_members, n_steps, n_targets)
  - ensemble_mean_scaled or mean_scaled shape: (n_steps, n_targets)
  - ensemble_std_scaled or spread_scaled shape: (n_steps, n_targets)

Optional physical-unit datasets are reused when present:

  - y_true_physical
  - ensemble_mean_physical

If physical-unit truth or mean datasets are absent, the script descales the
scaled arrays using scaled_h5_path:/scaling.

UQ methods applied
------------------

Unless uq_methods is explicitly provided, all five methods are run:

  1. ensemble_conformal_target_trajectory
     MACE-Trajectory: per-target trajectory-wise ensemble-normalized conformal intervals.  Each
     calibration profile contributes one max-over-horizon score per target.

  2. ensemble_conformal_target_horizon
     MACE-Horizon: per-target/per-horizon ensemble-normalized conformal intervals.  Quantiles
     are computed independently for each horizon and target.

  3. absolute_conformal_target_horizon
     Per-target/per-horizon absolute-residual conformal intervals centered on the
     saved ensemble mean.  No ensemble-spread normalization is used.

  4. absolute_conformal_target_trajectory
     Per-target trajectory-wise absolute-residual conformal intervals centered on
     the saved ensemble mean.  Each calibration profile contributes one
     max-over-horizon absolute score per target.

  5. raw_ensemble_2sigma
     Uncalibrated ensemble mean +/- 2 sigma using the same saved ensemble mean
     and spread.  No conformal guarantee is claimed.

All conformal calibration is performed in scaled target space.  Physical-unit
truth, center predictions, lower bounds, and upper bounds are produced only after
scaled-space intervals are constructed.

Outputs
-------

Artifacts are written under:

    <uq_output_dir>/uq_comparison/

The top-level comparison directory contains:

  - uq_methods_manifest.json
  - shared_ensemble_metadata.json
  - calibration_ensemble_predictions.h5
  - test_ensemble_predictions.h5

Each method has its own subdirectory containing:

  - calibration_metadata.json or method_metadata.json
  - calibration_scores.h5 when conformal scores are present
  - calibration_forecasts.h5
  - test_forecasts.h5
  - coverage_metrics.json

The method forecast HDF5 files use a standardized schema with y_true, y_pred,
lower, upper, interval_width and their scaled counterparts, plus spread_scaled
and optional effective_scale_scaled, normalized_abs_error, and
member_predictions_scaled.

Metrics
-------

For every method, coverage_metrics.json reports marginal pointwise coverage,
targetwise trajectory coverage, complete multivariate trajectory coverage as a
diagnostic, interval-width summaries, normalized widths, interval score, and
coverage deviations from the nominal level.  The primary coverage type depends
on the method metadata: trajectory methods emphasize targetwise trajectory
coverage, horizon methods emphasize marginal pointwise horizon/target coverage,
and raw_ensemble_2sigma reports empirical metrics without a conformal guarantee.


Simultaneous MACE/UQ profile visualization
------------------------------------------

Use scripts/plot_mace_uq_profile_comparison.py to overlay several UQ methods on
the same 4x4 profile figure.  The preferred input is the exact
forecast_plots/selected_forecast_profiles.json produced by train_lstm_ensemble.py:

    PYTHONPATH=src python scripts/plot_mace_uq_profile_comparison.py \
      --methods-manifest-json <uq_output_dir>/uq_comparison/uq_methods_manifest.json \
      --selected-profiles-json <ensemble_output_dir>/forecast_plots/selected_forecast_profiles.json \
      --out-dir <plot_output_dir>

If --uq-methods is omitted, all five methods are plotted.  A fallback can select
profiles from a difficulty CSV using the shared quantile-bin selection helper in
rabl.machine_learning.profile_selection.

Multi-method analysis outputs
-----------------------------

The analyzer writes separate pointwise and trajectory coverage-width tradeoff
CSVs/plots.  Cross-target aggregate widths and interval scores use scaled-space
intervals; per-target physical-width columns remain in each target variable's own
physical units.  Additional target calibration diagnostics quantify low-spread or
near-sigma-floor behavior for every target, including x_steam_out.
